# JP Tag Assistant

日本語 | [English](README.md)

**日本語で画像生成用のタグを探し、プロンプトに追加できるツールです。**

「膝立ち」「四つんばい」「腕組み」「横顔」など、描きたいものを日本語で検索できます。候補には英語タグ・日本語訳・投稿数が表示され、クリックしてプロンプトに追加できます。関連候補をたどりながら、ポーズや背景などの表現を広げることもできます。

AUTOMATIC1111／Forge／Forge - Neo／reForgeの拡張機能として利用できます。ComfyUI用のカスタムノードも含まれています。

## 主な機能

- 日本語の単語・登録済みの別名からDanbooruタグを検索
- 英語タグ・別名での検索。`all fours` や `from below` など、スペースを含む入力にも対応
- 候補をクリックしてプロンプトに追加。もう一度クリックすると、その操作で追加したタグを削除
- Shift＋クリックでネガティブプロンプトに追加・削除
- 選んだタグと一緒に使われやすいタグを「関連候補」に表示
- 関連候補の種類を切り替え、戻る・進むで探索履歴を移動
- Danbooruのカテゴリに基づく「版権/キャラ除外」
- 日本語／英語の表示切り替え、WebUIのライト／ダークテーマに合わせた配色
- ユーザー辞書による検索語・別名の追加

タグ補完拡張と併用できます。英語で入力中の補完にはtagcomplete、日本語から表現を探す際にはJP Tag Assistant、という使い分けができます。

## インストールと更新

### AUTOMATIC1111／Forge／reForge

1. 使用するWebUIの `extensions/a1111-sd-webui-jp-tag-assistant` にこのリポジトリを配置します。
2. WebUIを再起動します。
3. txt2imgまたはimg2imgを開きます。
4. ネガティブプロンプト欄の下にある「JP Tag Assistant」を開きます。

Gitでインストールする場合は、WebUIのフォルダーで次を実行します。

```sh
git clone https://github.com/dr1610/a1111-sd-webui-jp-tag-assistant.git extensions/a1111-sd-webui-jp-tag-assistant
```

更新はWebUIの拡張機能管理、または拡張機能のフォルダーでの `git pull --ff-only` から行えます。更新後は**WebUIを再起動し、ブラウザーでCtrl＋F5**を押してください。Python側の検索処理を更新した場合、ブラウザーの再読み込みだけでは反映されません。

Stability Matrixで複数のパッケージを使っている場合は、**実際に起動するパッケージ内の拡張機能**を更新してください。reForge側を更新しても、別にインストールされたForge - Neo側には反映されません。

### ComfyUI

1. `ComfyUI/custom_nodes/a1111-sd-webui-jp-tag-assistant` にこのリポジトリを配置します。
2. ComfyUIを再起動します。
3. 「JP Tag Assistant」カテゴリから `JP Tag Assistant Search` ノードを追加します。
4. `query` に日本語または英語を入力します。
5. `tags` の出力を文字列入力に対応したノードへ接続するか、`candidates`・`related` の内容を確認します。

ComfyUI版は文字列を出力するノードです。WebUI版の検索パネルやクリックによるプロンプト編集とは操作が異なります。

`related_limit` の初期値は `0` です。関連候補が必要な場合に増やしてください。関連データの初回読み込みには時間がかかる場合があります。

## 検索と関連候補

検索欄に入力すると候補を検索します。「検索」ボタンでも実行できます。日本語の変換中は検索を待ち、変換確定後に検索します。

「膝」のような短い入力から「膝立ち」などの長い候補を探せます。一方、入力語の末尾や途中に偶然含まれる短い辞書語を拾う逆方向の部分一致は行いません。

文章をLLMで翻訳する機能ではなく、辞書とタグの照合による検索です。日本語訳や別名が未登録の場合は、英語タグで検索するか、ユーザー辞書に追加してください。

候補を選ぶと、そのタグを基に関連候補を検索します。関連候補の種類は検索ボタン付近のメニューで変更できます。

| 表示 | 内容 |
| --- | --- |
| 自動 | 選んだタグから関連候補の種類を推定 |
| おすすめ | 一般カテゴリの関連タグ |
| 人物 | 人物・ポーズ・身体・服装などに関わる候補 |
| 背景・小物 | 場所・背景・物などに関わる候補 |
| 画風・品質 | 画風や品質に関わる候補 |
| NSFW | 成人向けの関連タグを優先 |
| すべて | 関連候補のカテゴリ制限を解除 |
| オフ | 関連候補を表示しない |

分類は排他的ではありません。「人物」に成人向けのタグが含まれることもあります。NSFWは成人向けタグを優先するモードであり、それ以外を完全に除外する設定ではありません。

「版権/キャラ除外」は検索候補に対し、Danbooruでcopyright（カテゴリ3）またはcharacter（カテゴリ4）に分類されたタグを除外します。作品名らしい単語を推測して除外する機能ではなく、作者カテゴリも除外対象ではありません。

関連データがないタグや、選択した種類に合うデータがない場合、関連候補は出ません。候補が多いときは一覧内をスクロールしてください。

## 表示言語と設定

WebUIの「設定」内にある「JP Tag Assistant」から変更できます。

**`Display language / 表示言語` は初期状態で `Japanese` です。** 「候補」「関連候補」「検索」、入力欄、ツールチップ、検索状態、関連候補のメニューが日本語になります。`English` を選ぶと英語表示になります。設定を適用した後、ブラウザーを再読み込みしてください。

| 設定名 | 内容 |
| --- | --- |
| Enable JP Tag Assistant | 機能の有効・無効 |
| Maximum search results | 検索候補の最大数 |
| Maximum related tags | 関連候補の最大数 |
| Related tag mode default | 関連候補の初期モード |
| Display language / 表示言語 | 日本語／英語の表示切り替え |
| Exclude copyright/character candidates by default | 版権/キャラ除外の初期状態 |
| Use machine-translated Japanese labels | 機械翻訳された日本語ラベルの使用 |
| Maximum cached relations per tag | タグごとに保持する関連データ数 |

## キーボード操作

WebUI版の検索欄で使用できます。

| 操作 | 動作 |
| --- | --- |
| ↑／↓ | 選択中の候補を移動 |
| Enter／Tab | 選択中の候補をプロンプトに追加 |
| Shift＋Enter／Shift＋Tab | ネガティブプロンプトに追加 |
| Esc | パネルを閉じる |

日本語入力の変換確定には、上記のタグ挿入操作を適用しません。

## ユーザー辞書

拡張機能内の `tags/jp_tag_user.csv` に、UTF-8のCSVで登録できます。別名は `|` で区切ります。

```csv
ja,tag,aliases
腕組み,crossed_arms,腕を組む|両腕を組む
素腕,bare_arms,腕出し|腕が出ている
```

配布辞書の `jp_tag_dictionary.csv` を直接編集するより、ユーザー辞書に追加すると更新時に管理しやすくなります。変更後はWebUIまたはComfyUIを再起動してください。
